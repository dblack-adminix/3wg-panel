# 3WG Easy Core

Упрощённая редакция для одного администратора и одного VPN-сервера.
Отдельный проект сборки; протоколы, конфиги, API и интерфейс используют
общую кодовую базу с расширенной редакцией 3WG Core.

## Первая версия

- Пиры WireGuard и AmneziaWG, включение, отключение, удаление.
- QR, скачивание конфигов, сроки действия и лимиты трафика.
- Краткая сводка на главной и состояние протоколов.
- Ручные резервные копии и восстановление.
- API-ключи, Telegram, Prometheus/Grafana, P2P Guard, обновления.
- Навигация и рабочие страницы как в Core: Главная, WG/AWG status,
  группа «Управление» с API-ключами, мониторингом, P2P Guard, обновлениями и backup.

В редакции Easy нет пользовательских кабинетов, управления ролями,
просмотра аудита, мастера миграции, сетевых инструментов и расписания backup.
Их API-маршруты также исключены. Запись внутреннего аудита сохраняется.
Вход разрешён только владельцу из PANEL_USER/PANEL_PASSWORD.
API-ключи владельца сохраняют доступ к включённым функциям.

## Установка

На отдельном сервере из корня checkout:

```bash
bash easy-core/install.sh
```

Используется общий установщик с редакцией easy, каталогом
`/opt/3wg-easy-core`, образом и контейнером `3wg-easy-core`.
Он поддерживает создание протоколов и подключение существующих.
Не подключайте две панели к одним и тем же VPN-контейнерам одновременно.

## Независимая Docker-сборка

```bash
docker build -f easy-core/Dockerfile -t 3wg-easy-core:local .
```

Для Compose подготовьте `easy-core/.env` по `.env.example`: задайте
непустые PANEL_PASSWORD и SESSION_SECRET, реальные домены, имена и настройки
VPN-контейнеров. Пример не содержит рабочего пароля. Секреты генерируйте
отдельно, например `openssl rand -hex 32`. `.env` должен иметь права 600.

```bash
docker compose -f easy-core/compose.yaml up -d --build
```

Compose использует отдельные каталоги data, clients, backups внутри easy-core
и слушает 127.0.0.1:18081. VPN-контейнеры должны быть уже установлены.
Публикация HTTPS настраивается отдельно. Compose не устанавливает host runner:
обновление выполняется пересборкой образа. Web-обновление доступно при установке
через установщик с host runner.

## Обновления и редакции

Редакция сохраняется как `PANEL_EDITION=easy` в `.env`.
Общий `scripts/update.sh` читает её и собирает соответствующий интерфейс.
Docker-сборка задаёт её отдельно через `VITE_PANEL_EDITION=easy`.
По умолчанию существующие установки остаются на редакции core.
Номер версии пока общий: исправления общей части выпускаются одновременно.

База и формат пиров общие. Переключение на Core должно выполняться с резервной
копией и пересборкой интерфейса; сохранение данных не равно миграции VPN-сервера.
Автоматический мастер перехода между редакциями в эту версию не входит.

До клиентского тиражирования остаётся отдельный этап исправления известных
проблем общей авторизации: отзыв сессий и проверки владельца в legacy-маршрутах
Core. Easy закрывает вход обычных пользователей, но это не заменяет исправление
общего механизма сессий. Первая версия предназначена для пилотной проверки.
